**Pronunciation Practice** targets the individual sounds you find hard. It's on both the web app and the AI app, sharing one set of scores. It has **Practice** and **Progress** tabs.

## Practice

Work through practice sessions built around specific sound pairs (for example /iː/ vs /ɪ/, or /v/ vs /w/).

![Pronunciation practice sessions](/images/student-guide/10-pronunciation-practice.png)

- Each session shows its **target sounds**, item count, and status (**In Progress** / **Ready**).
- Tap **Continue Practice** (or **Start**) to work through the items, speaking each one so the app can score you.

## Progress

See how you're doing overall.

![Pronunciation progress and phoneme analysis](/images/student-guide/11-pronunciation-progress.png)

- **Sentences assessed**, **Pronunciation** average, **Fluency** average, and the number of **Problem Sounds** that still need work.
- **Phoneme Error Analysis** — your hardest sounds (from your baseline assessment), each with attempts, errors, and a score, so you know exactly what to drill.

<Tip>
Start with the **Baseline Assessment** (offered on the AI app home screen) so the app knows which sounds to prioritize for you.
</Tip>
